Case study

GAnalyst

An AI agent that connects to Google Analytics 4 and answers plain-English questions about site traffic — with charts and summaries generated on the fly. Built end to end, including every bug fixed along the way.

Objective

As a marketing analyst, I wanted two things at once: a genuinely useful tool for querying GA4 without digging through report menus, and a real, hands-on understanding of how AI agents actually work — not just reading about tool use and OAuth, but building something that depends on getting them right.

How it started

The idea was simple to say and harder to build: connect an AI agent to Google Analytics so it could answer traffic questions directly, generate charts, and summarize trends — a chat interface standing in for a GA4 dashboard. The scope was deliberately a full web app (not just a script), with real OAuth login so it could eventually be shared with others, not just run privately on one machine.

Workflow

The build happened in stages, each one surfacing a real problem to solve:

  • Scaffolding — Next.js app, GA4 Data API client, and a Claude tool-use agent loop, built and verified in a sandboxed environment first.
  • Local setup — Google Cloud OAuth credentials, an Anthropic API key, and environment variables, hitting real beginner friction points: disk space running out mid-install, a hidden duplicate API key line silently overriding the real one, and a TextEdit rich-text paste silently corrupting a key.
  • A real session bug — the OAuth login loop turned out to be caused by using an outdated cookie-handling pattern (req/res) instead of the App Router's next/headers cookies API. Diagnosed from server logs, fixed, rebuilt, verified.
  • Visual design — moved off default Tailwind styling to a deliberate "measurement instrument" identity: paper background, brass accent, serif display type, monospace data readouts.
  • Validation — rather than trusting answers by default, built the habit of cross-checking the agent's numbers against the real GA4 dashboard, and understanding where GA4's own quirks (sampling, thresholding, a globally shared demo-account quota) could look like bugs but weren't.

Architecture

Three parts talk to each other, with the backend as the only thing holding credentials:

Browser (chat UI)
  ↕
Next.js backend — API routes + encrypted session cookie
  ↕          ↕
Google (OAuth + GA4 Data API)    Claude API (reasoning + tool calls)

When a question comes in, Claude doesn't fetch data itself — it requests a specific, narrow tool call (run_ga4_report with exact metrics/dimensions/dates), the backend executes the real GA4 API call, and the result is handed back to Claude to reason over and turn into an answer, optionally with a chart. This tool-use loop can repeat several times per question before Claude has enough to respond.

Final outcome

A working chat interface that connects to any GA4 property via OAuth (including Google's public demo account, so it's testable without needing your own site), answers traffic questions with real fetched data, renders inline charts, and is deployable to Vercel as a live, shareable app rather than a local-only script.

Learnings

Tool design determines agent reliability more than the model does. Narrow, specific tools (fetch this exact report) produce predictable behavior; vague ones invite guessing.

AI answers need validation, not blind trust. Building a small "golden set" of questions with known answers, and checking groundedness against the raw data GA4 actually returned, is the difference between a demo and something usable.

Most real bugs during this build were environment issues, not code issues — disk space, duplicate env lines, a text editor silently altering characters. Debugging systematically (checking file contents directly, isolating one variable at a time) mattered more than any single line of code.

A dashboard and a chat agent solve different problems. Fixed, known metrics don't need an LLM in the loop at all — only open-ended questions do. Knowing when not to reach for AI is part of using it well.
